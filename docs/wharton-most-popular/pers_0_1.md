# 前  言 

 Preface  

  
  

在我们身边有很多这样的人，他们总是非常忙碌，双手几乎没离开过手机或电脑键盘。有过多事务需要处理，同时注意力不会较长时间关注某一件事，在种种因素的共同影响下，这些人很难做到有效的沟通。今天，分散人们注意力的事情比以往任何时候都多，表述信息的人一直努力尝试突破繁杂声音的影响，从而进行有说服力的沟通。伴随着这一沟通现状的出现，《让松鼠聚焦：沃顿商学院最受欢迎的说服课》得以问世，书中包含了指导性理论和实用技巧。希望本书能够成为忙碌的人们必备的工具，以及想要成为一个更有说服力的沟通者手中的必备书籍。

斯科特博士并没有谴责那些注意力不集中的听众，而是接受了这一现实，并把它转化为演讲者的优势——一个能够考虑到信息的复杂性及信息量因素的简便技巧。这背后的秘密当然是要了解听众，但这一点往往说起来容易做起来难。作为一个沟通专家，斯科特博士帮助我们了解如何通过设置一个简单易行的题目（又称作橡果策略 ACORN）让听众的注意力集中在我们的信息上。斯科特博士所倡导的沟通方式是一种类似于常识的双向沟通方式，一种真实的对话和交流方式，实际上就是创造和传递有说服力信息这一策略的结果。她将帮助你找到听众的共同点（甚至是那些最为刻薄的听众），进行有效沟通，实现清晰表达信息，而听众易于理解。

我们和斯科特博士共事多年，她身上所具备的专业知识和教授沟通技巧的热情是非常出众的。阅读《让松鼠聚焦：沃顿商学院最受欢迎的说服课》一书，我们相信读者会发现斯科特博士身上的天赋，能够将一个通常令人抗拒的话题变得易于接受，且富有乐趣。
