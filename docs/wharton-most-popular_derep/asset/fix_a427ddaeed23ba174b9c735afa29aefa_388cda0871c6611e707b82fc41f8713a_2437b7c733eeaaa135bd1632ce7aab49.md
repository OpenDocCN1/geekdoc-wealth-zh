# 善良需要边界：懂得给予的人，更要懂得辨人

先把一个常见误会拆开：待人温和、好说话、乐于助人，并不等同于利他。心理学早期把利他塞进了亲和性这个大筐，后来的拆解更细：同情与礼貌是两条可分开的维度；同情更贴近诚实、谦卑，而不是亲和性本身；亲和性也无法直接代表给予者的价值取向。本书重心放在给予、索取、互惠这三类行为的直接研究上；只有极少数地方引用亲和性量表，因为题目本身就指向助人，比如“我喜欢帮助他人”。为保护隐私，莉莉安·鲍尔、皮特·奥代特故事里的布拉德和里奇、后文提到的萨米尔·贾恩，均为化名。

## 一、皮特：从共情软肋到识别伪装

先说皮特·奥代特。他先被布拉德卷走客户和资金，数年后又与里奇合伙。里奇刚出现时热情周到，亲和感很强。同事看得清楚：那些支持动作只是包装，里奇本质上在索取；皮特才是持续贡献的人，而里奇几乎榨干了皮特的价值。里奇年薪超过三十万，却对公司收入没有推动。他住在澳洲黄金海岸，清晨泡海滩，十点才进办公室，中午又去酒吧。皮特后来感慨，布拉德让他看清索取型人格的样貌，所以认出里奇是彻头彻尾的索取者：自己总在补位，里奇像吸管一样连着公司账户；不关心同事，不服务客户，还污染文化，利用皮特对合伙人的忠诚占便宜——公司是他们从零搭起来的。

皮特忍了很久。某周一，里奇宣布买下黄金海岸一套数百万的房子，缺口十万，直接从公司账户划走。当天董事会上，里奇提前离席去酒吧会友。这成了压垮皮特的最后一击。他明白信任已破裂，向董事会承诺让里奇担责，计划尚未成形，先涌上来的是愧疚：“里奇待我像兄长。”同事也说，这事对谁都难，对皮特更难，因为他习惯给予，知道里奇将面对什么，还想帮对方绕开。

皮特栽在共情上。共情是设想他人痛苦时自己也会疼，它既能驱动善行，也是软肋。布拉德工作不顺、跳槽时，皮特感受到对方的难受，几乎没犹豫就买下布拉德的客户；想到里奇被夺权会多痛苦，他又下不去手。

这种陷阱在谈判实验里很清晰。研究者分两组谈电子产品，一半是陌生人，一半是约会情侣；每组一买一卖。直觉以为情侣更信任、分享更多信息，会更容易双赢。结果相反：情侣的共同收益更少，爱得越深表现越差。热恋中的人像无条件给予者，默认体察伴侣需求、立刻让步、不顾自身利益。研究者指出，这种关心导致他们不去寻找整合方案，而是挑选容易达成、双方都不太满意的结果，形成“温和解决”。无私给予者在谈判桌上也一样：认同“我总把别人需要放在自己前面”的人，更怕关系紧张，于是靠让渡价值来顺从对手。

皮特后来换了做法：不再体会里奇的感受，而是推演里奇的思维。关键发现是，里奇喜欢新鲜挑战，那就顺着他自私的逻辑来。皮特说：你明显不爱公司日常运营，不如交给我，我觉得自己够成熟，能扛这些事。里奇同意，还表示想参与创业空间的一些特别项目，为公司找新收入。皮特支持，并开始召集董事会议。

皮特能走通，是因为他钻进里奇的脑袋，而不是心里。哥伦比亚大学心理学家亚当·加林斯基的研究表明：谈判时过度共鸣、太盯着对手情绪，容易过度付出；换位思考对手的想法和利益，更可能找到既满足对方又不牺牲自己的方案。皮特若继续同情里奇，就找不到这条路；把注意力从感受转到想法，他才能用索取者的视角看问题，再调整策略。

把里奇放到危害较小的角色后，皮特仍放不下帮里奇成功的愿望，同时清楚里奇仍有空间继续索取。于是他决定：信任，但保留核实。里奇可以自主做特别项目，但要为结果负责，每九十天汇报进展。“我给他机会衡量贡献，也让我们能衡量。”半年后，里奇没做出成果。皮特做正式分析，写董事会报告：“里奇最后没有贡献，而且不可否认，这是他自己的责任。我们拿出初步证据，说明他索取多于付出。”真相让里奇离开，也让皮特解脱。里奇被投票驱逐，带着股权走人。

皮特不再被人踩，他扳倒了一个索取者。后来他才知道，里奇的索取倾向超出预料：里奇从公司贷了一大笔钱，还欠银行的钱，最后皮特不得不开支票结账，因为里奇没钱还债。皮特当总经理一年后，里奇离开公司。十五个月后，皮特的公司利润跳到七位数，员工士气飙升，支出骤降，还在为经销商团体的年度公司奖项努力。

一旦给予型的人认识到“真诚性筛选”的价值，能把亲和力强的索取者识别为潜在伪装者，就能调整行为保护自己。皮特给出一条线索：和索取者打交道，要切到互惠模式。起初做给予者是明智的，因为信任难建易毁；但对方一旦明显露出索取行为，就该换互动风格，转向互惠——就像皮特要求里奇用创造价值来换回报。“别给索取者太多时间，也别把自己的时间浪费在他们身上，这已经成了我的本能。”皮特说。

实验也支持：让人们和搭档合作，搭档可能竞争也可能合作。无论搭档是谁，索取者都竞争性地行事；给予者会适应搭档——合作型就合作，竞争型就用更竞争的方式回应。博弈论把这叫“针锋相对”，一种纯粹互惠策略：先合作，继续保持合作，直到对手竞争；对手竞争后，用竞争匹配。它很有效，赢过许多博弈论锦标赛。但它有个“致命缺陷”，哈佛大学数学生物学家马丁·诺瓦克写道：它不够宽容，处理不了偶尔的事故。

诺瓦克发现，更好的办法是在给予和互惠之间切换。带善意的对等策略规则是“从不忘记好的回合，但有时要忘记不好的回合”。你以合作开始，继续合作，直到对手竞争；对方竞争时，一般不必总用竞争回应，而是仅在三分之二的情况下竞争，剩下三分之一用合作回应背叛。“带善意的对等策略”能轻松战胜一般对等策略，并防止被叛徒利用。它能达到强大平衡：奖励给予、挫败索取，但不过度惩罚。它也有风险：鼓励多数人像给予者一样行事，却给索取者留下机会——当其他人都合作时，索取者可以靠竞争“东山再起”。但在人际关系和声望越来越透明的世界里，索取者想再利用给予者，越来越难。按诺瓦克的说法，“慷慨的策略占据长久的优势”。

这是一种利他且自利的策略。无私的给予者会犯“总是相信人”的错误；利他且自利的给予者也会把信任作为默认起点，但当对方行为或声望表明他是索取者时，愿意调整互动风格。利他且自利意味着：给予者通过后视镜关注自己的利益，把核实当作信任的前提；与索取者打交道时，转入互惠者模式是一种自我保护。但每三次里最好留一次回到给予者模式，给所谓的索取者一个救赎机会。皮特对里奇正是这样：给了里奇保住饭碗的机会。利他且自利的给予者持有乐观信念，正如兰迪·波许在《最后一课》里表达的：耐心等下去，人往往会以惊喜的方式让你折服。

这种策略的价值，也体现在第一章桑普森的故事和林肯身上。林肯在伊利诺伊州参议员选举中主动放弃，让莱曼·特朗布尔得以击败詹姆斯·希尔兹。后来特朗布尔试图妨碍林肯的事业，遭到众人谴责。林肯的妻子玛丽·托德说这是“自私的背叛”，并与特朗布尔的妻子断交——对方曾是她最亲密的朋友之一，还在其婚礼上当过伴娘。林肯却更愿意宽恕，表达对特朗布尔的信任：“任何离间你我关系的努力都是无用的。”同时，为保护自己免受背叛，他也警告特朗布尔不要惹自己：尽管我对你的怀疑不比世上最好的朋友多，但我还是得不停与这类流言蜚语作斗争。特朗布尔回报了林肯，在下一次参议员选举中支持他。

一八五九年，芝加哥市长约翰·温特沃思指责诺曼·贾德密谋反对林肯、支持特朗布尔并推进自己的政治生涯。林肯的妻子从未原谅贾德，林肯也提醒贾德“你确实通过给特朗布尔投票来反对我”，但他用宽宏大量的方式解读贾德的决定：“我认为，并且表达过一千次，这对于我没有什么不公平的。”林肯帮贾德调解与温特沃思的冲突，但也要求回报：对我来说，如果得不到伊利诺伊州代表团的支持，会非常痛苦；“在这件事上，你能否在你的后花园里帮我个小忙？”贾德满足了这个请求。接下来一周，他在《芝加哥邮报》刊登重要社论支持林肯，确保共和党代表大会在芝加哥召开——那里有林肯的支持者，而诋毁林肯的人被安排在后排，影响力受限。林肯的默认做法符合给予者风格，但他也意识到偶尔做出互惠行为的价值，并从“慷慨的针锋相对”中获益。他秘书的女儿解释说，林肯对他人观点的敏锐洞察，让他在预测对手行动时有着不可思议的准确性，并且能用这种预测挫败对手。

贾森·盖勒指导德勤新员工时，也采取“慷慨的针锋相对”。与新员工首次会面后，他会提议：“如果这次谈话有帮助，我愿意每月做一次。”对方同意，他就把每月会面排进日程，没有终止日期。每月会面既创造给予机会，也帮他弄清谁可能是索取者。“持续对话有一部分价值在于，你可以很快分辨出谁在伪装，因为良好的谈话和良好的关系彼此互为基础，”盖勒解释说，“每六个月伪装一次很容易，但经常这样做就不容易了。这正是我鼓励人们安排这种会面的部分原因：能分辨真诚，同时产生最大影响。”如果他把同事鉴别为索取者，会继续给予，但越来越小心：“我不会减少帮助，但帮助方式会不同。我会倾听并保持专注，但我们不会进行对话；这里不会涉及多少指导和教诲。我并不会有意减少支持，但人性会让你把时间投入到回报最大的地方——对我们双方都是如此。”

莉莉安·鲍尔起初并没有依据请求者的交互风格调整给予。起初筛选真诚性之前，她对每个人都极其慷慨。转变发生在一位家族朋友来向她求建议之后：对方想进一家顶尖咨询公司。鲍尔用标志性慷慨回应，花了五十多个小时，在夜晚和周末指导这位候选人，还帮她在自己公司和几家竞争者公司之间建立关系。候选人最终收到鲍尔所在公司和一家竞争者的入职通知，并加入了鲍尔的公司。接下来，尽管鲍尔和同事在雇用过程中投入大量时间和精力，这位候选人却请求调到另一个国家的分公司，直接违反公司雇佣规则。鲍尔被一个亲和力强的索取者骗了。“所有讨论都是关于她自己的利益。从她谈论这个决定的方式可以很明显看出，这完全关于她自己；很明显，她会自取所需。”被利用之后，鲍尔学会小心地与索取者打交道。“在此之后，我对于她的感觉完全改变了，而且我不再愿意那么慷慨了。”

## 二、不敢开口的代价：果敢困境与收入差

男性和女性能力相当，但男性赚的钱明显更多。卡内基梅隆大学经济学家琳达·巴布科克面对数据很沮丧：都二十一世纪了，她们学校男性工商管理硕士毕业生的薪水仍比女性高七点六%。卡内基梅隆是世界顶尖科研机构之一，出过十八位诺贝尔奖得主，其中经济学奖得主就有七位。商学院提供计算金融学、计量金融学和软件工程学等学位，学员中超过四成进入金融领域。在这样一个强调数量的环境里，薪水统计仍显示女性面临“玻璃天花板”。巴布科克算过，三十五年职业生涯中，这种差异意味着每位女性平均损失超过一百万美金。

但事实是，性别差距并非“玻璃天花板”造成。男女收到的初始提议相似，差距在签署最终录用协议时出现。仔细检视后，巴布科克发现男女在“要不要要求更高薪水”上差异巨大：超过一半男性（百分之五十七）会尝试协商起薪，女性只有百分之七；愿意协商的男性数量是女性的八倍。那些确实协商了的学生——基本上是男性——薪水平均提高七点四%，这足以解释性别差异。

谈判意愿的差异不限于MBA的量化世界。另一项研究中，巴布科克和同事雇人玩四轮拼字游戏，报酬在三到十美元之间。游戏结束后，研究者像索取者一样只给最低限额三美元，并问：“三美元够不够？”结果，要求更多报酬的男性是女性的八倍。另一组研究类似，但研究者交三美元时没问是否足够：没有女性提出多要，百分之十三的男性主动要求更多。还有一组，研究者交三美元并说“具体报酬可以商量”：大多数男性（百分之五十九）抓住机会要求加薪，女性只有百分之十七。总体看，男性要求更多报酬的可能性是女性的八点三倍。每种情况里，女性都成了垫脚石，让索取者可以任意欺负。

研究显示，女性不像男性那样果断谈判，一个主要原因是担心违反社会期望——社会期望她们温暖、和善。但女性并不是唯一在谈判桌上容易受控制的人。垫脚石效应是一种诅咒，对两种性别的给予者都会产生影响。几项实验中，男性和女性给予者都愿意做出很大让步，只为达成协议、取悦谈判对象，即使他们有更好的选择。圣母大学蒂莫西·贾奇教授开展的一系列研究中，近四千名美国人填写了给予者问卷，表明自己帮助、照顾和信任他人的倾向程度。平均而言，给予者比不那么倾向给予的人收入低百分之十四，年收入少近七千美元。按性别统计，男性的收入损失是女性的三倍：女性给予者比其他人少挣百分之五点四七，差额一千八百二十八美元；男性给予者平均少挣百分之十八点三一，差额九千七百七十二美元。

正如“无力的沟通”那一章所说，给予者倾向于谦卑，不习惯直接、肯定地表达意见。更受控条件下的研究显示，在零和情境中，给予者常羞于争取自己的利益：商谈工资时，他们的请求比互惠者和索取者更温和，最终接受不太有利的结果。这种对果敢的不情愿，特别容易影响亲和力强的给予者，让他们付出金钱代价。

在一家专业服务公司，有一位我叫萨米尔·贾因的给予者，总是成为垫脚石效应的受害者。他在同级员工中排名第一，在整个公司美国东北部的全部雇员中排前百分之十，还花许多时间帮助同事、指导年轻员工。尽管是明星员工，他却眼看着其他公司的朋友更快升迁、赚更多钱，而他从没为自己的薪水谈判，也没要求晋升。有几次，他目睹果敢的同事——表现并不比他好——通过谈判赢得加薪和升迁，在组织阶梯上超过了他。“我没有努力推动这件事，让这样的事也发生在我身上。我不想让别人不舒服，或是超出我的限度。”

萨米尔在印度长大，从小就很容易被人影响，这让他成了家里的笑柄。他父亲出身贫寒，学会了做精明的谈判者，为所有东西讨价还价，把家庭带到中产水平。萨米尔在家庭保护中长大，不需要坚持己见。他的服从性让妻子很烦，她是个强硬的谈判者。他们刚开始约会时，萨米尔正准备租公寓。妻子插手，代表他谈判，把年租金减少了六百美元。他折服，也尴尬。从此，每当他们买东西，他都必须找妻子去谈判，因为他知道如果自己去，就会成为垫脚石。“实话实说，我因此羞愧了很长时间。”他承认。

离开专业服务公司后，萨米尔读了MBA，收到一家财富五百强医疗技术公司的工作邀请，这是他的理想雇主。他对提议条款并不完全满意，但像往常一样不愿谈判。“我感到尴尬。我喜欢我的老板，不想让他不舒服。”更糟的是，经济危机爆发，他的同事都没谈判就签了约。

善良不是无限额透支，信任也不是一次性买断。先给合作，再留核实；多数时候慷慨，偶尔宽容；该竞争时竞争，该回头时回头。这样的给予者，才既能温暖别人，也不把自己垫在脚下。
